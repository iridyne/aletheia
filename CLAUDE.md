# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

@AGENTS.md

This file exists only to import [`AGENTS.md`](AGENTS.md), the single copy of the
repository-wide rules: safety boundaries, D0/D1/D2 classification, commit/PR rules,
the stage map and the matched-guide router. Directory-local conventions and test
commands live in that directory's `AGENTS.md` (for example `frontend/`, `tests/`,
`core/aletheia/execution/`), each with a sibling `CLAUDE.md` that contains only
`@AGENTS.md`. Do not add rules here or in any nested `CLAUDE.md` —
`CONTRIBUTING.md` states the same rule to human contributors.
