- Reconcile every persisted `running` Operator task older than 30 minutes at startup.
  The task is marked `cancelled`, with `operator_runtime_recovery_timeout` and
  structured `running_task_expired` evidence; it is not represented as a completed
  or failed task.
- Preserve fresh running tasks for normal restart recovery.
- Add `cancelled` as an idempotent terminal Operator task state, including
  `completed_at` persistence and a `task_cancelled` audit event.
- Limit failed-task supervision alerts to the current 30-minute observation window;
  historical failures remain audit records but no longer permanently hold the
  Operator in a review/degraded state.
