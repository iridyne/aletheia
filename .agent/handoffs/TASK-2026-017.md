# TASK-2026-017 handoff

## Purpose

Fix a real bug discovered while completing TASK-2026-016: `workflow check
--strict` hard-fails for every previously-merged task because their recorded
evidence commits become unreachable from master after a squash-merge. Since
`--changed-since` does not scope this check, CI on master was effectively red
and would block all future PRs (including TASK-016's).

## Changes made

- `aletheia/agent_workflow.py::validate` (strict, done-task branch): when the
  best evidence commit is not a HEAD ancestor, probe whether it still exists
  with `git cat-file -e <sha>^{commit}`.
  - exists but unreachable (squash-merge orphan) → WARNING (proof was real)
  - does not exist at all (fabricated/typo) → ERROR
  - no successful evidence at all → ERROR (unchanged)
- Added AW-S10 spec claim + updated AW-S02 assertion (new error string).
- Updated `docs/design/agent_workflow_contract.md` with invariant AW-S10.
- 3 focused tests in `test_agent_workflow.py`: reachable=ok,
  exists-but-unreachable=warning, nonexistent=error.
