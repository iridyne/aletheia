# TASK-2026-007 handoff

## Purpose

Keep venue, canonical symbol, and market type intact when the Observer builds multi-timeframe market context, so perpetual reads and cache entries cannot fall back to spot.

## Boundary

Only the Observer market-context read path and its in-memory OHLCV cache identity.
Risk limits, order execution, sizing, filters, credentials, and live controls are excluded.

## Result

The Observer passes an `InstrumentId` through the provider instead of a CCXT-formatted
string. The context cache now keys reads by venue, canonical symbol, and market type,
and the degraded snapshot fallback uses the same market type. This prevents a perpetual
contract from being requested or displayed as spot data.
