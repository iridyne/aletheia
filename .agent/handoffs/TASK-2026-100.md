# TASK-2026-100 handoff

## Purpose

Make the immutable Aletheia modular-monolith artifact installable and verifiably
runnable as a stable macOS user instance that is isolated from the high-frequency
Git development checkout while sharing the canonical per-user `~/.aletheia`
runtime home.

## Changes made

- Converted the release manifest and archive naming from Windows-only to a
  platform-neutral `portable-source` contract while retaining Windows support.
- Declared Linux, macOS and Windows support plus platform runtime entrypoints.
- Stored Unix launchers with deterministic LF content and executable ZIP mode.
- Added a fail-closed macOS installer that verifies the SHA-256 sidecar and every
  manifest file hash/size, installs immutable SHA directories, synchronizes locked
  production dependencies, and atomically updates the `current` symlink.
- Added manifest-backed Unix start and readiness/health scripts. The stable start
  script refuses Git checkouts and relative runtime-state overrides.
- Added focused tests for portable metadata, executable modes, checksum rejection,
  installation and atomic activation, launcher guards, and workflow contracts.
- Extended GitHub Actions so the exact Windows-built artifact is downloaded on a
  clean macOS runner, installed under a temporary user application directory,
  bootstrapped against temporary `~/.aletheia`, started on the stable gateway,
  health-checked, stopped, and checked for LaunchAgent/repository-state pollution.
- Updated the operating documentation with the Mac stable/runtime layout and the
  rule that ordinary gateway lifecycle commands belong only to a fixed release;
  development checkouts use isolated `aletheia dev api` instances.
- Repaired the historical `TASK-2026-099` base commit to the reachable merge commit
  that actually introduced that completed task; a temporary diagnostic workflow
  used to identify this pre-existing full-history issue was removed.

## Risks

- This establishes verified manual installation and stable runtime isolation, not
  automatic checkpoint selection or promotion.
- A MacBook can suspend or power off; the stable instance remains suitable for
  active dogfooding but is not equivalent to a 24/7 always-on host.
- macOS LaunchAgent behavior is tested for non-registration in clean CI; the
  separate explicit-disable persistence fix remains in PR #106 and should be
  resolved before relying on user autostart controls.
