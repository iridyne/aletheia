# TASK-2026-077 handoff

## Purpose

Add five missing CI checks to ci.yml: fast regression tests (1868), integration tests (689), Python ruff lint, frontend ESLint, and gitleaks secrets scan. Fix real bugs found during lint setup.

## Changes made

**CI workflow (`.github/workflows/ci.yml`)**
- Added `secrets-scan` job: gitleaks/gitleaks-action@v2, full fetch-depth, blocks PRs with leaked secrets
- Added `fast-tests` job: `pytest -m fast`, 1868 unit tests, 20 min timeout
- Added `integration-tests` job: `pytest -m integration`, 689 cross-boundary tests, 20 min timeout
- Added `uv run ruff check aletheia/ tests/` step to existing `backend` job
- Added `npm run lint` step to existing `frontend` job before build

**Python lint setup (`pyproject.toml`)**
- Added `ruff>=0.9` to dev dependency group
- Added `[tool.ruff.lint]` config: `select = ["E", "F"]`, ignoring high-noise rules (E501, E402, F401, F841)

**Bug fixes found by ruff (aletheia/ source)**
- `aletheia/agent_shell/operator_loop.py`: removed unnecessary `f` prefix from two string literals (F541)
- `aletheia/gateway/reconciliation.py`: same fix (F541)
- `aletheia/server/routes/data.py`: removed redundant in-function re-imports of `timedelta` and `SerenityRunEvent` (F811)

**Bug fixes found by ruff (tests/)**
- `tests/specs/spec_defillama.py`: added missing `from aletheia.data.collectors.defillama import _DL_STABLECOINS_URL` import (F821 — real undefined name)
- `tests/specs/spec_hyperliquid.py`: added missing `from aletheia.data.collectors.hyperliquid import _HL_INFO_URL` import (F821 — real undefined name)
- Several test files: added `# noqa` suppressions for intentional patterns (function-scoped `json` param name, single-line mock classes)

**Frontend lint setup**
- `frontend/package.json`: added `eslint`, `@typescript-eslint/*`, `eslint-plugin-react-hooks` to devDependencies; added `"lint": "eslint src/"` script
- `frontend/eslint.config.js`: new flat-config file; disabled aggressive react-hooks v5 rules (set-state-in-effect, purity, immutability, refs) for existing code base
- `frontend/src/charts/PnLChart.tsx`: moved `useState(false)` before early returns to fix `rules-of-hooks` violation (conditional hook call — real React bug)
- `frontend/src/App.tsx`: rewrote ternary side-effect as `if/else` to fix `no-unused-expressions` (real ESLint error)
