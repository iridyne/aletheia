  two-minute core lane retains primary-venue orderbook/Funding/OI, and a new

  cross-venue, macro, and optional public sources.

  remain serial.

  real-time Funding/OI path into best-effort context maintenance.
- Added the deterministic offline starvation shadow and the bounded-lane spec,
  then updated the scheduler and data-collection design contracts.
