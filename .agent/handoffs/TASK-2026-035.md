# TASK-2026-035 handoff

## Purpose

Generalize reconciliation thrash detection from adopted-only reopen rows to any scoped native or adopted reopen after an administrative close, persist and deduplicate integrity incidents, block destructive reconciliation cycles, globally refreeze Learning across restart, and expose honest doctor diagnostics without changing close classification or execution behavior.

## Changes made

- Generalized the close/reopen detector from `reconciled_gone -> adopted` to central
  administrative/maintenance classification followed by any native or adopted open
  event. Matching now includes execution mode, broker, account environment, market
  type, canonical symbol and direction; explicit unequal account fingerprints cannot
  match, and source remains explanatory.
- Added restart-safe `reconciliation_integrity_incidents` persistence, one-active-row
  deduplication, source/identity evidence, a two-observation five-minute clean gate,
  and explicit actor/reason resolution with an atomic database audit event.
- Made demo reconciliation fail closed before adoption/orphan-close while churn is
  current, an incident remains active, or the detector/state store is unavailable.
  One clean poll and process reload cannot self-clear the breaker; live behavior remains
  classify/alert-only.
- Connected the durable incident to the shared Learning control gate, scheduler jobs,
  prospective experiment authority, Operator prompt bundle, market-observer advisory
  memory, learned ranker guards, learned persona appetite, progressive unlock and
  persona rollout. Read-only settlement/shadow measurement remains available; a
  conservative active Risk lesson is intentionally not removed.
- Updated doctor to use central closure categories and report current scoped churn,
  reopen source mix, durable incident id, Learning freeze reason and clean-gate progress.
- Made OI-B04/OI-C01 GREEN, updated the older adopted-position design claims, data
  model/execution/Learning SDD, issue status and implementation plan. The plan now
  explicitly keeps Operator, calibration, alpha, Risk and every independent performance
  statistics reader in RG-T08A/B/C and RG-T09 as mandatory follow-on debt.
