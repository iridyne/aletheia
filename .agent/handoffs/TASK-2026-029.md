# TASK-2026-029 handoff

## Purpose

Remove the Agent Activity height cap, decouple it from the right rail, and make the Overview rail responsive at canonical breakpoints without changing backend or trading behavior.

## Changes made

- Removed the code that measured the right rail and imposed that height on Agent
  Activity. The activity card now grows with its content and the page owns scrolling.
- Simplified AgentFeed by removing its height prop, inline height style, and nested
  scrolling class. The existing latest-40 item limit remains unchanged.
- Changed the desktop grid to a fluid 320px-380px right rail. At 1100px the rail cards
  become a two-column grid; at 700px they return to one column.
- Kept the independent height protection on Approval, Risk, System, and Go-Live cards
  so unusually long control content stays contained.
- Added `tests/test_overview_layout.py` to prevent the old measured-height behavior or
  mismatched breakpoints from returning.
- Recorded the change in `docs/_ai/DEVLOG.md`.
