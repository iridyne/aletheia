# TASK-2026-052 handoff

## Purpose

Close the AT-02 authority gap by binding approved measurement evidence to the same hypothesis, predecessor experiment, and declared horizon before any paper influence can be authorized.

## Changes made

- Hardened the single Learning authority decision so a new paper stage can rely on an activation record only when it belongs to that experiment's closed immediate predecessor, the same hypothesis, and the same requested path.
- Bound both activation and current-stage measurement records to the hypothesis's declared horizon. Foreign, mismatched-path, or malformed records now keep the static baseline before either the current or legacy authority route is consulted.
- Added regressions for a wrong horizon, a foreign activation record, a foreign current-stage record, a missing predecessor, and a mismatched path. The read-only authority decision leaves persisted experiment state untouched.
- Documented the existing paper-only Learning Settings API entry and added a regression so it cannot disappear from the endpoint index again.
- Updated the Learning contract and implementation plan with the extra identity-binding requirement.
