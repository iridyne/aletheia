## Purpose

Make the default runtime and configuration root platform-agnostic at ~/.aletheia, preserve explicit absolute overrides, isolate previews and developer claims, provide fail-closed legacy migration, and prove release bundles never write runtime state under the source package.

## Changes made

- Added a single platform-independent runtime-path authority. The default is the
  current user's `~/.aletheia`; `ALETHEIA_DATA_DIR` remains an absolute override.
- Redirected config, SQLite, secrets fallback, logs/audit, PID/routes,
  reflection, backup/artifact consumers, task claims, and isolated preview state
  away from repository-root `data/`.
- Added an explicit dry-run-first `runtime migrate-home` command. Apply mode
  preserves the source, includes the legacy adjacent `.env`, excludes transient
  process/SQLite files, validates hashes/config/SQLite/audit state, rolls back
  target-side partial copies, and writes its completion marker last.
- Updated the PR #104 release bundle manifest, Windows launcher, clean-extract
  verification, three-OS runtime-home CI contract, canonical documentation, and
  architecture tripwires.
