# TASK-2026-096 handoff

## Purpose

Create the first immutable Windows dogfood release bundle for Aletheia as a
single-machine modular monolith. Keep Python/React development complexity out of
the deployed artifact and keep durable trading state outside versioned release
directories.

## Changes made

- Added `ALETHEIA_DATA_DIR` as an absolute external durable-state override for the
  primary runtime while preserving repository-local defaults and preview isolation.
- Added focused subprocess and unit coverage for data-root selection.
- Added a deterministic whitelist bundle builder with per-file manifest hashes,
  ZIP checksum sidecar, 60 MiB warning and 100 MiB fail-closed limit.
- Added tests proving runtime-only contents, exclusion of runtime/development files,
  byte reproducibility, dashboard-build precondition and hard size enforcement.
- Added Windows release start and health-check PowerShell scripts.
- Added a Windows GitHub Actions workflow that builds the React dashboard, runs
  focused tests, creates the ZIP, performs a clean extraction/production dependency
  sync/external-data bootstrap check, and uploads the bundle plus size metadata.
- Added the modular-monolith release contract and registered focused workflow
  verification.
- Rebased the work logically onto the CI reliability branch without importing the
  stale TASK-2026-095 release metadata.
