# TASK-2026-008 handoff

## Purpose

Persist the next exact instrument after each completed observer attempt so bounded LLM cycles cover the full active pool across restarts without weakening the timeout guard.

## Result

The bounded observer loop now stores the next full instrument identity in SQLite.
Each completed attempt advances the state, while cancellation and a budget break leave
the in-flight or first skipped item eligible for the next cycle. Duplicate and removed
items are handled deterministically.
