# TASK-2026-006 handoff

## Purpose

Preserve exception type when the Serenity worker thread marks a failed research run, including empty-message timeouts.

## Result

The normal research pipeline and the background thread boundary both preserve the
exception class in their stored error detail and use the same classifier. Empty
`TimeoutError` now becomes `provider_timeout`, not `unknown_error`.
