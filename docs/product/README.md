
# product/ - Product Intent

Use this directory to answer what Aletheia is for, what is in scope, and how success is measured.

## Subfolders

| Folder | Use |
|---|---|
| `definition/` | Vision, PRD, and product direction |
| `gates/` | Metrics and phase gate criteria |
| `experiments/` | Experiment protocol, backlog, MVP gates |
| `documentation/` | Frozen history of the previous documentation migration |
| `capability-integrity/` | Evidence-first inventory, fact cards, and issue-ready product capability truth |

The canonical implementation-status summary is
[CAPABILITY_GROUND_TRUTH.md](CAPABILITY_GROUND_TRUTH.md).

## Agent Rule

Product docs define intent and supported scope. If implementation differs, do
not silently rewrite product intent; verify the mismatch, use GitHub Issues for
tracking, and update the appropriate Product Truth or Contract through the
normal review path.
