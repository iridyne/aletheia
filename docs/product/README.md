
# product/ - Product Intent

Use this directory to answer what Aletheia is for, what is in scope, and how success is measured.

## Subfolders

| Folder | Use |
|---|---|
| `definition/` | Vision, PRD, active scope, product direction |
| `gates/` | Metrics and phase gate criteria |
| `experiments/` | Experiment protocol, backlog, MVP gates |
| `documentation/` | Documentation-system plans and taxonomy decisions |

## Agent Rule

Product docs define intent. If implementation differs, do not silently rewrite product intent; record the drift in `issues/` or update the contract through the normal design/governance path.
