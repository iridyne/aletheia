# Frontend Research Lane

Read only the active numbered domain.

| Domain | Folder | Focus |
|---|---|---|
| 1 | `01-ui-design-system/` | Tokens, visual language, primitives, accessibility, and page-state presentation |
| 2 | `02-information-architecture/` | Shell, navigation, routes, bootstrap, onboarding, and loading boundaries |
| 3 | `03-data-components/` | Tables, charts, filters, search, watchlists, and high-density interaction |
| 4 | `04-client-state/` | TanStack Query, query keys, cache ownership, invalidation, and mutations |
| 5 | `05-api-contracts/` | API client, types, errors, permissions, initialization, and module boundaries |

Create a domain folder when its investigation begins. Its README defines the
scope; evidence reports use the shared template under `00-research-program/`.
Do not treat a visual preference as an architectural requirement without
identifying the user problem it solves.
