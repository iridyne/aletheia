
# references/ - External Reference Material

Use this directory for external systems, papers, captured pages, and benchmark comparisons. References are not authorization to implement.

## Subfolders

| Folder | Use |
|---|---|
| `external-systems/` | North-star comparisons, OpenAlice/prism, framework maps |
| `papers-and-benchmarks/` | Papers, competitors, benchmark surveys |
| `coriva.eu.org/articles/` | Markdown captures from Coriva reference pages |
| `coriva.eu.org/captured-html/` | Raw captured HTML paired with article markdown |

## Routed External-System Studies

- `external-systems/tickflow-stock-panel/` — source-bound study of TickFlow Stock
  Panel's frontend, backend data plane, I/O consistency, realtime delivery, and
  reusable lessons for Aletheia. Start at its local `README.md`; the material is
  evidence and inspiration, not implementation authorization.

## Agent Rule

When borrowing from a reference, create or update a plan and check governance boundaries first.
