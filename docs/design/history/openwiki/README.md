# Archived OpenWiki architecture snapshot

This snapshot preserves the OpenWiki pages present at `b7ec0d670`. They describe
the former local simulated exchange, PaperTrader/Ranker and Operator entry loop,
local cash/funding, simulator-backed Learning stages and old configuration defaults.
They are not current implementation or operating instructions. Other subsystem
notes remain here as part of the same historical snapshot, without recertifying
its module inventory, commands, links or capability claims.

Original page bodies and their relative layout are preserved. Some links already
pointed to nonexistent pages; those historical gaps do not define current work.

[capability ground truth](../../../product/CAPABILITY_GROUND_TRUTH.md),
[Entry Plan contract](../../contracts/entry-plan-contract.md), and
