## 一、CLUSTR100 AI MARKET WATCH（官方异动观察 bot）

最高频出现的格式（全篇出现几十次），**只观察异动、不给买卖点**：

```
📡 CLUSTR100 AI MARKET WATCH
━━━━━━━━━━━━━━━━━━━━
SUIUSDT
|
🟢 偏多结构
🎯 关注等级
B
信心 78/100
■■■■■■■■□□
📌 结论
方向：
🟢 偏多关注
结构：趋势初期 / 早期
状态：⚡ 异动进行中
⏱ 有效期：未来 1-3 小时，过期需重新看数据
🧩 核心依据
1. 4h 三连阳涨幅超 6%
2. OI 3h +16.7%
3. 24h +21.9% 放量
⚡ 时机说明
1h 连续放量阳线突破前高, OI 同步扩张, 距 24h 高仅 0.4% 但仍有空间
⚠️ 主要风险
1. 散户多空比 2.01 偏多
2. BTC 横盘可能拖累
👀 接下来观察
1. OI 是否继续配合价格方向
2. 主动买卖力量是否延续
3. 15m / 1h 收盘能否确认结构
4. BTC 是否突然反向带动山寨波动
━━━━━━━━━━━━━━━━━━━━
⚠️ 仅为市场异动观察，不构成投资建议。
不提供具体买卖点位，请自行控制风险。
🕒
05/11 01:17 CST
```

**偏空版核心依据示例**（同模板，方向相反）：
```
🔴 偏空结构 / 结构：出货 / 中期
🧩 核心依据：
1. OI 1h -11%
2. Premium -0.17%
3. taker 0.86
⚡ 时机说明：1h已破近期支撑, taker 0.86主动卖压, 距24h高-8%
⚠️ 主要风险：1. OI/市值1718%极端杠杆  2. 散户多空比2.16偏多
```

**设计解读**：
- 结构二分：偏多=「趋势初期/早期」，偏空=「出货/中期」。
- 三要素恒定：**核心依据**（OI变化 + Premium/费率 + taker）、**时机说明**、**主要风险**。
- 「接下来观察」4 条永远固定（OI配合/买卖力量/15m1h收盘确认/BTC联动）——这是给人留的二次确认清单。
- **信心固定 78/100、等级固定 B**：说明这是无差别异动播报，不做精选（这也是它被吐槽「用的人多了信号失真」的原因）。
- 风险栏会点名「vol/OI 53x 刷量」「Top10 82% 集中」「OI/市值 极端杠杆」等操纵风险——**重要的反指过滤项**。

## 二、庄家雷达 Master（人世间，AI 综合分析排序版）

带**多因子评分 + 推荐排序**的全市场扫描，给具体点位：

```
🏦 庄家雷达 Master
⏰ 2026-05-08 14:40 CST
【AI 综合分析 — 推荐排序】
#1 D#90次推荐(首推+32%) — 🅱️追涨 评分107
评分 107/100 | 🚀追涨 | R/R 1.5x
🏦大户多1.54
💰主力净多$1M
📊多空人数1.2x
📊吃单卖0.84
💰基差-0.05%贴水
#90次推荐
(上浮32%)
入场 0.01489      止损 0.0136988
止盈 0.016676800000000002 → 0.0171235
现价 0.01489      涨跌   -22.6%
形态 ➡️震荡偏多     7日+30% 位33%
市值         $11M 费率   +0.000%
OI       -4.4%   成交量 $112M
...
#4 BTC#12次推荐 — 🅲做空 评分99
评分 99/100 | 🔴做空 | R/R 0x
🏦大户空0.70
🤖做空AI评分99
📊多空人数0.8x
💰基差-0.04%贴水
...
---
📊 扫描摘要: 扫606个币 | 发现32个机会
🚀 拉盘中: 2个 | 🥷 潜伏机会: 3个
💡 策略: 拉盘信号需OI+量能确认，潜伏信号需费率负+OI增
```

**信号类型标签**（重要分类体系）：
- `🅱️追涨` / `🚀追涨` —— 拉盘中、追势
- `🅲做空` —— 做空
- `🅲反向做多` —— 大户/主力做空但散户追多时的反向（轧空逻辑）

**设计解读**：
- **多因子评分**：大户多空比、主力净多($)、多空人数比、吃单买卖比、基差(贴水/溢价)、广场提及次数。
- **「#N 次推荐 + 首推涨幅」**：同一币累计被推荐次数 + 从首推至今涨幅 → 量化「这个信号家族历史靠不靠谱」。
- **扫描摘要**分「拉盘中 / 潜伏机会」两类，并给出**核心策略口诀**：「拉盘信号需 OI+量能确认，潜伏信号需费率负+OI增」。
- R/R（盈亏比）字段：追涨 1.5x，做空标 0x（不给止盈，纯方向）。
- 注意张德楷质疑：「OI 流出追涨是不是危险了点」——评分高但 OI 在流出时要警惕。

## 三、猎人量化手机雷达（张德楷，波次追踪版）★ 最精炼

手机端单币详情卡，核心创新是 **「#波次_N」热度计数**：

```
🎯 #LAYER  [168.0M] 异动
🛢 OI(资金): +14.79%
💰 现价: 0.15482
(距首发 +63.67% | 距上次 +4.66%)
🔥 热度: #波次_15 距首发 (14h32m)，上次 (0h9m)
📈 趋势: 1H +29.68% | 15m +1.28%
🏦 市值: 69.2M
💣 仓市比: 22.4%
⚡ 费率: -0.5085%
⚖ 多空比: 1.09
🌟 评分: #共 4 分
🏗 入场价格 (止盈2.5%):
 一档: 0.13674 (-11.7%)
 二挡: 0.12263 (-20.8%)
 止损: 0.11424 (-26.2%)
👉 🕵 LAYER 历史
💎 猎人量化手机雷达
```

**异动等级标签**（按 OI/价格变化分级）：`微动` → `异动` → `暴拉` / `暴动`

**24H 热度榜格式**：
```
📊 猎人雷达·24H 热度榜 🚀 距首发涨幅 Top10
1. #LAB 📈+476.97%  2. #SIREN 📈+63.56%  3. #NOT 📈+61.35%
4. #COLLECT 📈+43.68%  5. #AGT 📈+25.98% ...
```

**广场首发信号版（photo_153/182，给散户引流用）**：
```
多头启动 $MLN [17.8M]
$MLN 这波是多头首发，现价 2.343。
仓市比 18.1%，控盘味道已经出来了，先卡位置。
拉升刚启动，直接拿延伸，这里适合先跟进再管理。
新仓跟上来了，OI +1.34%，后续延伸值得直接跟。
费率现在是 0.0050%（费率转正，资金主动做多），做多成本不拖后腿，顺势更舒服。
从趋势角度看，+7.48% 还不算尾端，更像刚开始动。
信号时间: 05-14 08:55:45
#BinanceSquare #量化雷达 #合约异动
```

**设计解读**：
- **「#波次_N」是核心创新**：同一币每次异动报警计为一个「波次」，记录「距首发时长 + 距上次时长」。波次越多说明热度越持续。群里有「1-6 波次信号」和「7+ 波次信号」分频道。
- **「距首发 / 距上次」涨幅**：量化信号家族的累计收益与新鲜度。
- **仓市比（OI/市值）**：张德楷反复用它判断「控盘程度」。photo_30 标 142.2% 被红圈强调——**仓市比畸高 = 强控盘/操纵风险**。
- 评分用「#共 N 分」（1-5 分制，比百分制更克制）。
- 入场同样分「一档/二挡/止损」三价，止盈固定 2.5%。

## 四、粥粥-Scan Hermes（ICT/SMC 结构化信号）★ 最专业

模仿主观交易员（ICT/SMC 体系）的信号，**带完整结构推理 + AI 结构分析 + 风控提示**。这是群里公认「给 AI 用挺稳」的范式（Anthony 语）：

```
🔴 TONUSDT 做空 ⭐中 [ICT/SMC]

📍 结构区域: 空头订单块 OB
区间: 2.077 ~ 2.153

💰 当前价格: 2.089
🛑 止损: 2.163
🎯 TP1: 2.044 (快速落袋)
🎯 TP2: 2.010 (主仓离场)
🧳 仓位建议: 轻仓 (信号偏弱，谨慎参与)

🔍 层3确认: 流动性扫除
🌐 BTC 大盘: ➡横盘
🧮 资金费率: 0.0050% | 多空比: 1.09

触发原因:
 ✅ 4H 空头结构 (BOS确认)
 ✅ 价格回踩空头订单块 (2.077 ~ 2.153)
 ✅ 15M 流动性扫除确认 (成交量 2.6x)
 ✅ 1H CVD下降 (主力资金方向与信号一致, delta=-723995)

━━━━━━━━━━━━━━━━━
🤖 AI结构分析:
【结构评估】信号可信度中等偏高：4H BOS + OB回踩 + 15M流动性扫除三层共振，
CVD主力净卖出与方向一致是最强支撑；最大风险是BTC横盘随时可能带动TON假突破
OB上沿，OI下降-5.9%说明多空双方都在撤场，动能不足。

【入场建议】
等待条件: 在 OB 区间内等 1H 或 15M 出现看跌吞没/针形(下影刺穿后快速收回)，收盘确认后再入场，不追高。
入场区间: 2.077 ~ 2.153
加仓位: 若价格反弹至 2.130~2.143 区间 (OB中...)

【止损止盈】（多头FVG示例，photo_165/166/167）
止损: 6.766 (FVG中轴偏下，价格跌破此位意味着缺口被有效击穿、多头结构失效)
TP1: 7.342 (40%仓位，触及后止损上移至入场均价，锁定无风险)
TP2: 7.611 (70%仓位，触及后止损上移至TP1，让利润奔跑)
TP3: 7.880 (流动性目标，清扫上方摆动高点，RR≈4.1，剩余仓位持有)

【风控提示】
BTC大盘 📈上涨提供顺风环境 | ATR熔断L2风险，建议控制仓位在正常的50%以内 |
恐慌贪婪43偏恐惧，市场情绪不支持激进加仓 | 资金费率0.0122%偏多头付费，
每8小时持仓成本约0.012%，中线持仓1-2天费率损耗可忽略不计。

【综合建议】
推荐
核心理由: 4H BOS结构清晰 + OI三级台阶放量(资金真实流入是最硬的信号), BTC顺风,
FVG提供精准入场区间, RR4.1值得参与; 唯一制约是情绪偏恐惧, 需等K线形态确认再入, 不盲目抢入。
⚠️ 仅供参考，手动决策，盈亏自负
```

**设计解读（这套模板最值得抄）**：
- **多层确认（层3确认机制）**：4H 结构(BOS) → 价格回踩 OB/FVG → 15M 流动性扫除 → 1H CVD 方向一致。**四层共振才出信号**。
- **CVD（累计成交量 Delta）** 作为「主力资金方向」的硬指标，delta 负值 = 主力净卖出。
- **结构化止损**：放在「OB 失效位 / FVG 中轴」而非固定百分比，并用 **ATR** 度量（如「低于 OB 低端约 1.8 个 ATR」）。
- **ATR 熔断分级（L1/L2）**：波动过大时自动「首仓减半 ×0.5、加仓间距放宽 ×1.5」。
- **恐慌贪婪指数**入场过滤：偏恐惧时不激进加仓、要等 K 线确认。
- **资金费率成本核算**：明确算出「持仓 N 天的费率损耗」，判断中线持仓是否划算。
- **三段止盈 + 止损逐级上移**（详见 [02](02_策略构建方法论.md) 范式 B）。
- **可信度分级**：⭐中 / 偏弱，且明确「轻仓、谨慎参与」。

## 六、单笔平仓通知格式（qifei0003）

```
🎯 移动止盈 | RIVERUSDT
做多 | ⏱ 持仓: 1分钟
入场: 7.777000 → 出场: 7.535000
数量: 6.4 张
盈利: +0.08U (+0.0%)
💸 手续费: -0.02U
💰 净盈亏: +0.05U
```
**设计解读**：平仓通知必须含「**毛盈利 - 手续费 = 净盈亏**」三行，否则会忽略手续费侵蚀（这单毛赚 0.08U，扣费后只剩 0.05U，高频下手续费吃掉一半利润）。

## 七、策略分组战绩通知（Allen.Ai）

```
pump_short: 13单 / 61.54% / +27.2036U
crash_bounce: 9单 / 55.56% / +8.0320U
```
**设计解读**：按**策略名分组**统计（单数/胜率/盈亏），能看出哪个子策略真有效。pump_short（拉升后做空）和 crash_bounce（暴跌反弹）是两个独立子策略。
