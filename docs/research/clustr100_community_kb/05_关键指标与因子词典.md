# 05 · 关键指标与因子词典

> 信号里的每个字段到底什么意思、实战怎么用、群里怎么吐槽它。按重要性排序。

---

## OI（Open Interest，未平仓合约量 / 持仓量）

- **含义**：当前市场上未平仓的合约总量，代表「资金在不在场」。
- **实战用法**：
  - `OI ↑ + 价 ↑` = 新多资金进场（健康上涨）。
  - `OI ↑ + 价 ↓` = 新空进场（健康下跌）。
  - `OI ↓ + 价 ↑` = 空头平仓推动（轧空，可能不持久）。
  - `OI 价跌背离`（价创新高但 OI 开始降）= **多头获利了结，反转信号**（s3 模块、Icarus 模型都用）。
- **群内态度（重要）**：
  - 是最被滥用的指标。**张德楷：「我已经放弃 OI 这个指标了」**「好像现在都是 OI…」。
  - **PIZZA：「不能只看 OI，特别是 alpha 的小币种，操纵的太狠。」**
  - 浪里个浪：「OI 还得加点别的做判断。」
  - 万刀哥的反向思考：「OI 这个怎么说？买得多才会显示，其实狗庄早就买够了，只是做给你看而已。」→ **OI 可被操纵，是给散户看的诱饵**。
  - 单看 OI 失效，必须配合 量能 / 费率 / taker 多维确认。

## 资金费率（Funding Rate，费率）★ 群内研究最深

- **含义**：永续合约多空之间每 8 小时（部分交易所 1 小时）结算的费用，用来锚定合约价 ≈ 现货价。
  - 费率为正 → 多头付钱给空头（做多情绪高、买盘强）。
  - 费率为负 → 空头付钱给多头（做空情绪高、卖盘强）。
- **实战逻辑（s3 模块）**：「**负费率 = 空头燃料，庄家拉盘爆空单**」——负费率时大量空单，庄家拉盘可触发连环爆仓（轧空）。
- **完整实战法则见 [07 资金费率实战](07_资金费率实战_猎人交易法则.md)**（张德楷专文）。
- **持仓成本核算**（粥粥 bot）：「资金费率 0.0122% 偏多头付费，每 8 小时持仓成本约 0.012%，中线持仓 1-2 天费率损耗可忽略不计」——中线可忽略，**高频/扛费率裸跑要警惕**（Allen.Ai：「资金费会先扛不住」）。
- **基差（贴水/溢价）**：合约价 vs 现货价的差。「基差 -0.05% 贴水」= 合约比现货便宜（做空情绪）。庄家「通过控制现货与合约价差（维持负费率），在高位横盘时每小时收海量散户资金费，以战养战维持价格」。

## taker（吃单买卖比 / taker ratio）

- **含义**：主动买单 vs 主动卖单的比例（谁在主动成交）。
  - `taker > 1` = 主动买盘强（吃单买）。
  - `taker < 1`（如 0.7）= **主动卖压**（吃单卖）。
- **实战**：CLUSTR100 信号里偏空必带「taker 0.7x 主动卖压」；偏多带「taker 1.1x 主动买盘活跃」。是判断**当下买卖力量**的即时指标。
- 边界情况：「taker 比 1.55 但主动卖压已现」——taker 数值与价格走势背离时要小心（量价背离）。

---

## 多空比（多空人数比 / LS Ratio）

- **含义**：两种口径——「多空**人数**比」（散户账户数）和「大户多空比」（大户持仓方向）。
- **实战（反指逻辑）**：
  - **散户多空比 > 2 = 散户极度追多 → 反指，警惕轧空/插针**。CLUSTR100 风险栏常标「散户多空比 2.01 偏多」。
  - **大户多空比**：庄家雷达里「🏦大户多 1.54」是顺势信号；「大户空 0.70 + 散户追多」→ 触发「🅲反向做多」（轧空逻辑）。
  - LS Ratio 倒挂（s1 模块）：「散户多空比上升、大户多空比下降」= 主力把高价筹码派发给散户 = 顶部信号。

---

## 仓市比（OI / 市值）★ 张德楷最爱

- **含义**：未平仓合约价值 / 流通市值，衡量「控盘/杠杆化程度」。
- **实战**：
  - 仓市比畸高（如 142.2%、213%、1718%）= **极端杠杆化 / 强控盘 / 操纵风险大**，反弹/插针风险高（CLUSTR100、猎人雷达都把它列为风险项）。
  - 仓市比低（如 2.1%、5.1%）= 合约影响力小，价格更受现货抛压驱动。
  - 张德楷用「仓市比 18.1%，控盘味道已经出来了」判断庄家是否入场。

---

## CVD（Cumulative Volume Delta，累计成交量 Delta）

- **含义**：累计的（主动买量 - 主动卖量），代表**主力资金的真实方向**。
- **实战（粥粥 ICT 信号）**：「1H CVD 下降（主力资金方向与信号一致，delta=-723995）」——CVD 为负且下降 = 主力净卖出，是做空信号的「最强支撑」。
- 被视为比 OI 更难操纵的「主力方向」指标。

---

## VWAP（成交量加权平均价）

- **含义**：按成交量加权的平均成交价，机构常用的「公允价」基准。
- **实战**：photo_39 面板顶部直接显示 VWAP $2286.5 作为参考锚。
- **数据源坑**：张德楷「欧意（OKX）给 VWAP 价格」，但 Cyrus 指出「**币安没这个指标**」→ 用币安数据要自己算 VWAP。

---

## vol/OI（成交量 / 持仓量，刷量识别）

- **含义**：成交量相对持仓量的倍数，**识别刷量/做量**。
- **实战**：CLUSTR100 风险栏「vol/OI 53x 刷量」「57.9x 重度刷量」「69x 数据可信度低」——倍数极高说明在刷量，数据失真，**该币应过滤掉**。

---

## 热度 / 波次（张德楷 + s3 模块特有）

- **波次（#波次_N）**：同一币每次异动报警计为一波，记录「距首发时长 + 距上次时长」。波次多 = 热度持续，是张德楷雷达的核心创新计数。
- **广场提及（📣广场提及3次）**：币安广场/X 上被提及次数，作为热度因子（需爬广场数据）。
- **CG 热搜**：CoinGecko Trending 榜，s3 模块用「CG 热搜 + 放量 = 资金涌入信号」。

## 价格行为 / 结构类（ICT/SMC 体系）

| 术语 | 含义 | 实战用法 |
|------|------|---------|
| **BOS** (Break of Structure) | 结构突破 | 4H BOS 确认趋势方向（多头/空头结构成立） |
| **OB** (Order Block) | 订单块 | 主力挂单区间，价格回踩 OB 是入场点；跌破 OB 失效位止损 |
| **FVG** (Fair Value Gap) | 公允价值缺口 | 价格快速移动留下的缺口，回补缺口区间是精准入场区；FVG 中轴是止损参考 |
| **流动性扫除** (Liquidity Sweep) | 扫除止损流动性 | 价格刺穿关键位扫掉止损后反转，15M 确认（成交量放大 2.6x） |
| **ATR** (Average True Range) | 平均真实波幅 | 度量波动率；止损放「OB 下方 1.8 个 ATR」；ATR 熔断分级控仓 |
| **吞没/针形** | K 线形态 | 入场确认信号（看跌吞没、下影针形刺穿后收回） |

> **Anthony 关键评价**：「FVG 给人类交易和玄学没啥区别，给 AI 用还挺稳的」——ICT/SMC 这套结构化术语恰恰适合让 AI 量化执行。

## 横盘天数（自建衍生指标）

- 交易所**不直接提供**这个数值（XingLin Yang 反复问怎么算）。
- **算法（Sorrows）**：对接币安 K 线，「系统根据 K 线数据 日K +（OHLC + 成交额）计算」——自己写规则统计连续震荡的天数。
- 浪里个浪：「横盘是自己加规则去计算。」

## 形态标签词典（庄家雷达）

| 标签 | 含义 |
|------|------|
| ➡️震荡偏多 / 震荡偏空 | 区间震荡但有方向倾向 |
| 📊震荡区间 | 纯区间 |
| `7日+30% 位33%` | 7 日涨幅 +30%，当前价处于 7 日区间的 33% 分位（位置高低） |
| 微动 / 异动 / 暴拉 / 暴动 | 按 OI/价格变化的异动等级（猎人雷达） |
| 追涨 / 潜伏 | 拉盘中(追势) vs 低位潜伏(埋伏) |

## L2 数据 / 订单流（高频专属）

- **L2 数据 = 订单簿深度数据**（不是订单流）。qiheng san 纠正：「L2 数据不是那个订单流。」
- 张德楷：「二阶差分要用」——对订单簿数据做二阶差分捕捉变化加速度。
- 仅 L2 级高频策略才需要（张德楷自称「L2 级别高频」），中低频不必（滑点模型一节已说明）。
