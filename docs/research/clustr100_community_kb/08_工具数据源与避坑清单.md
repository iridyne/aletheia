## 二、爬虫 / 反爬

- **币安广场**：可以直接爬（PIZZA：「我每天都在爬，让 AI 想办法」）。但 iso9 说「币安广场爬不了」——可能需要技巧/反爬应对。
- **OKX 广场**：没网页端、无 api，难爬（PIZZA：「要研究一下」）。
- **反爬定义**（给新手）：flyawei：「很多数据通过 python 爬虫获取，有些网站会有反爬虫措施」；浪里个浪：「不让你抓数据，有些要你花钱买 api。」
- **让 AI 扫 GitHub**：薄言：「我忘记 AI 能扫描 github 了」——找 YouTube/SMC skill 可让 AI 去 GitHub 搜（有专门的 youtube-transcript skill）。
- **YouTube 喂数据**：YouTube 有反 IP 爬限制，「agent 喂不进去」；解法——GitHub 上有专门的 youtube skill（`youtube-transcript-api`），或推特搜 SMC 策略 PDF。

## 三、模型 API 接入方式

| 方式 | 说明 | 坑 |
|------|------|-----|
| 官方 API（按 token 计费） | 最稳，无次数限制，充钱按量 | 贵；Claude 要求 KYC，**新号容易秒封**（iso9：英国手机号+outlook 邮箱，没开就被封） |
| 订阅 OAuth（Plus/Pro 会员） | 让 AI 帮你登录 codex/claude 终端授权，调 CLI | 上下文受限：GPT5.5 订阅 270K（Plus），Pro 400K；Claude 1M |
| 中转站 | 朋友的中转便宜（~4 毛/刀？） | **会降智**；张德楷：「claude 千万不要找中转」「朋友的应该没问题」；魔童：「中转站感觉都不靠谱」；罗素：「外面中转站踩了坑怕了」 |
| 免费额度 | TRAE 免费额度、DeepSeek 薅羊毛 | XingLin Yang 平常用 TRAE 免费额度 |

**Codex CLI 调用法（PIZZA）**：
> 「直接在服务器上调用 codex cli。比如你有包月会员，让 AI 帮你登录 codex 终端，会给你一个授权链接，授权之后终端登录了，每次要分析哪个币，让他写个代码，要分析的时候就调用 codex cli。」

**GPT-5.5 Plus 限额**（M，5/28）：「Plus 用户每三小时有 160 次 GPT-5.5 权限，用完后**静默降级到 mini**。」

## 五、安全与骗局

- **API Key 安全**：用 .env 隔离；只开**交易权限，不开提现权限**；不要把含提现权限的 key 给 AI 或中转。
- **群内骗局识别**：群里多次出现私信诈骗（「分享内幕新币 20 倍」），被踢。Wiggins：「居然想在一窝聪明人里试图行骗。」**任何主动私信给你「内幕消息/带你赚钱」的都是骗子。**
- **不发币、不发二维码、不拉人推广**：群规，违者踢。
- **Claude 封号**：KYC 要求 + 新号易封，注册要谨慎（用干净的手机号/邮箱）。
