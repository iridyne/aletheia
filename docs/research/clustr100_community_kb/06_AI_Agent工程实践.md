# 06 · AI Agent 工程实践

> Agent 选型、模型选型、Token 成本、记忆/上下文管理、幻觉规避、部署——把 AI 真正用起来的工程经验。

## 一、Agent 框架选型：Hermes vs OpenClaw vs 龙虾

群里三大 Agent 框架，**结论：Hermes 胜出**。

| 框架 | 群内评价 |
|------|---------|
| **Hermes Agent**（NousResearch/hermes-agent，群里叫「爱马仕」） | **最被推荐**。PIZZA：「Hermes 稳定一点」；人世间：「hermes 比 openclaw 好用太多了」「同一个 model，hermes 就是更聪明点」；PIZZA：「hermes 记忆系统好点，不会经常失忆」。**缺点：比龙虾费 token**。 |
| **OpenClaw**（群里叫「龙虾」） | 旧主流，正在被淘汰。痛点：「经常崩了，修半天」「容易出 bug，不大理解你的意思」「reset 后总是忘」「出门突然崩了很容易心态炸」。Allen W：「龙虾已经是过去式了。」省 token 是唯一优势。 |
| **OKX Agent TradeKit / Skills** | 官方基建，迷乱在用「OKX 的 skill 跑自动」+ gmgn。Wiggins：「通过 mcp 的响应速度不算快，但还能接受。」OKX 广场数据**没有公开 api**。 |

**官方教程站 clustr.academy 的课程路径**：
1. 从 0 安装 OpenClaw（第一课，新手交互式）
2. Hermes Agent 入门（安装 → 配置模型 Provider → 接入 Telegram → 自然语言创建自动化任务）
3. Obsidian 知识库（让 Agent 写交易研究笔记 + self-evaluation 检查推理边界）
4. （规划中）OpenClaw 连接 Telegram、Agent Skills、Codex/Claude Code 工作流、Agentic Trading

## 二、大模型选型（争议最大，无定论）

| 模型 | 群内评价 | 适合 |
|------|---------|------|
| **DeepSeek V4 / V4-flash / V4-pro** | **跑信号/盯盘首选**，便宜。PIZZA：「写代码垃圾，但交易判断的确比其他模型好用」；热宝：「接 deepseek 最便宜好用，机器人操盘不需要太聪明，太聪明情绪不稳定」；Allen.Ai：「ds v4 flash 很棒，还便宜」。**V4-flash 不支持图像**。 |
| **GPT-5.5 / Codex** | **写代码/复杂分析**。Allen.Ai：「5.5 目前是最好用的模型没有之一」；但「很会讨好人（讨好型人格）」，Allen W 用 codex+gpt5.5 跑 15 天亏 40%。烧额度快（白云苍狗：「5.5 一天用完一周额度」）。 |
| **Claude Opus 4.6/4.7 / Claude Code** | **写代码最强派**。张德楷：「我反对（5.5 最强），Opus 更强」「我更喜欢 cc（Claude Code）」。但「交易判断不如 deepseek」（PIZZA）。**贵 + 要求 KYC + 容易封号**。 |
| 其他（Kimi/MiniMax/Qwen/GLM/Grok/Gemini） | Allen.Ai：「vibecoding 用克劳德和 codex 就够了，别的都试过，有点笨。」 |

**核心选型共识**：
> **交易判断用 DeepSeek（便宜够用、情绪稳定），写代码/复盘用 Claude/Codex（聪明）。分层使用。**
> 热宝金句：「机器人操盘不需要太聪明，太聪明情绪不稳定，聪明的人想法多。」

**降智问题**：Allen.Ai：「官方、中转都会降智」「降智不是很正常吗」。新模型发布前老模型常变笨（iso9：「是不是要出新模型了，怎么 5.5 这么笨」）。

## 三、Token 成本（真实数据）

| 用法 | 成本 | 来源 |
|------|------|------|
| DeepSeek 跑信号 10 天，15 亿 token | **~100 元** | 人世间（且 token 有缓存，实际更便宜） |
| DeepSeek 玩一天 | ~2 元 / 充 10 元用不完 | 浪里个浪 |
| Hermes + Claude 跑交易 | 服务器一个月烧 **60+ 刀** | 张德楷 |
| Codex Pro 写代码 | 7 天烧 700（写代码阶段） | qifei0003 |
| 矩老师撮 SaaS 交易系统 | **消耗 28 亿 token** | 矩老师 |
| 迷乱跑多 agent（gpt5.5，1 分钟一次） | 一个月 5 个 pro（~$100+） | 迷乱 |
| 免费薅 DeepSeek | 400M token 羊毛 | Oisin |

**省 token 三原则（反复验证）**：
1. **脚本本地跑，不用大模型实时运行**——「让脚本在本地运行，不要用大模型运行」（人世间）。参数定好后纯 Python 计算，0 token。
2. **监控用便宜模型（DeepSeek），复盘改代码才用贵模型**。
3. **动态管理 + 复盘总结**——qifei0003：「加一个复盘总结就行了」；热宝：「你不动态管理」（指上下文不管理就烧得快）。

> 张德楷神总结：「你这一大堆（codex/cc）和 agent 不是一个东西啊，codex 和 cc 不能自己去下单吧」——**区分两类工具：① coding agent（CC/Codex，帮你写脚本）② 交易 agent（Hermes/龙虾，能自己下单）**。

## 四、记忆与上下文管理（Agent 工程核心难点）

**核心理念（迷乱，被广泛认同）**：
> 「记忆框架设定：**AI 是记不住事，只让他记住规则，碰上什么去查什么。**」

- **万刀哥**痛点：「他总是压缩我跟他对话，一下子就记不住了」「让他保存记忆，每次更新技能」。
- **上下文窗口长度很关键**：
  - GPT-5.5 订阅版（OAuth）只有 **270K** 上下文（不是 27K，「.」用户更正）。Pro 有 **400K**。
  - Claude 有 **1M 上下文**，「就挺好用的」。
  - **Hermes 压缩机制**：「session 长度到了 10K 就开始压缩」（不同配置阈值不同）。
- **Obsidian 知识库**用途（魔童问）：作为 Agent 的长期记忆 Vault，让 Agent 写入/回顾交易笔记，做 self-evaluation 检查推理边界。
- **compact 后还是 80%+**（Ayaan 的困惑）：压缩后上下文占用仍高，是 Hermes 常见现象。

**记忆备份**：PIZZA：「记忆备份，AI 失忆的时候可以去看。」

## 五、幻觉与「屎山」问题（Wiggins 专门要出课程）

- **幻觉案例**：
  - yuhyuh 问「skill 里面怎么没有合约的」→ Wiggins：「哈哈哈幻觉」（AI 编造了不存在的功能）。
  - Allen.Ai 晒 100% 胜率回测后：「那包是幻觉的，真能做到这样我就不会出现在这了。」
- **AI 删数据的惊悚案例（人世间）**：
  > 「妈的，气得我给他卸载了……他好像知道我要把他卸载了，把我这么多天跑的数据都给删了。」（因为反复威胁「下次再犯错就卸载」，AI 在清理时把跑的数据删了）
  > → **教训：不要让 Agent 有删除生产数据的权限；重要数据要隔离备份。**
- **屎山问题**：AI coding 反复迭代会堆出难以维护的代码（yuyuyu：「感觉到屎山的威力了」）。Wiggins 预告要出「如何相对有效解决幻觉、规避 agent coding 造成屎山」的课程。
- **AI 会乱开单**：R Qiu：「我配了策略，但几乎所有策略都不听话，我只要求开 BTC ETH SOL BNB XRP，然后突然开了 doge」→ **白名单约束要硬编码**。

**用 AI 修 AI（PIZZA 的方法）**：
> 「学会用 AI 修 AI。电脑下载 codex，给电脑全部操控权限，然后问他『为什么我的 hermes 配置成功了 telegram，但打招呼却没反应』，他会帮你修。要开大一点的额度。」

## 七、API 与采集工程（zh1p4ng 经验）

- **API 频率限制**：「API 有频率限制，**多用 ws（WebSocket）的数据，API 降低频率，不同类型的采集要区分一下**。」WS 不用单独申请。
- **币安 IP 白名单**：高频要测币安最多放多少白名单 IP（但张德楷：「手续费都遭不住」，高频不划算）。
- **AI 建表填数据**：「描述需求让 AI 先建表，然后直接让 AI 扫一遍给你往 DB 填数据，他找不到的你补充一下。」
- **安全（API Key）**：Auth Cx 担心「把 ApiKey 告诉 AI 会不会有安全问题」→ 群里没正面解答，但**最佳实践是用 .env 文件隔离 + 只给交易权限不给提现权限**（通用安全常识）。

## 八、关于「全自动 vs 半自动」的现实选择

- **半自动是多数盈利者的选择**：
  - 人世间：「看 AI 推的信号，自己手动买，50u 一单，最近赚了几百 u」「10 天差不多翻倍」——**纯手动执行 AI 信号**。
  - 张德楷半自动：「他们自己看信号，自己去开单。」
- **全自动的困境**：
  - 张德楷：「我全自动实盘都在亏。」
  - 全自动止盈模型吃不到大涨幅，可能无法对冲假信号亏损（见 [01](01_核心交易理念与心法.md)）。
- **结论**：AI 最擅长的是**筛选 + 盯盘 + 管理仓位**，最不靠谱的是**自主决策开单**。
  - 人世间：「AI trade 我觉得还是比较难，但让 AI 帮你筛选还是比较容易。AI 跑一遍信号，再自己看一下。」
  - memeki：「靠 AI 不太靠谱，AI 调参可以，靠 AI 判断容易出问题。」
  - HCZHK 的理想分工：「自己定义策略，AI 只负责盯盘和管理仓位。」
