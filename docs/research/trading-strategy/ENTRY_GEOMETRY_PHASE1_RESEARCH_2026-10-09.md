# 入场 / 止损 / 止盈几何：第一阶段研究（#3850，2026-10-09）

> 本文是**研究证据**，不是契约，也不是已批准的语义。研究全程只读。资料来源包括：交易理论（Al Brooks、YTC、
> ICT/SMC、Wyckoff、经典支撑阻力、ATR/吊灯止损、成交量分布、斐波那契、MAE/MFE 方法）、竞品代码（AstraQuant、
> nofx、OpenAlice、Freqtrade、Jesse、Hummingbot）、我们自己的几何实现，以及在 Fedora 上用真实 K 线做的
> MAE/MFE 研究。综合方案经独立审查代理挑错后修订，修订记录见第 7 节。
> 凡标 UNVERIFIED 的内容，都还没有一手来源核实。

术语：
- **R**：一份止损距离。盈亏都用 R 计。
- **MAE / MFE**：持仓期间价格往不利方向 / 有利方向走得最远的距离。
- **ATR15 / ATR1h**：15 分钟 / 1 小时 K 线的 14 期平均真实波幅，用来衡量"一根 K 线通常动多少"。
- **净 R**：扣掉往返手续费 0.12% 和止损滑点之后的 R。

---

## 0. 一句话结论

**在现有样本内，"在决策时刻按市价入场"看不出方向优势**。几何（止损、止盈放在哪里）只能决定摩擦和波动怎么
分摊，本身造不出期望收益。所以第一步要先**证明方向有没有优势**，再谈用几何参数放大优势。

这一结论的边界（审查要求必须写明）：
- 样本只有 **9 个 UTC 日**，行情状态全部是 bull，集中在 09-24 至 09-30。
- 入场按"决策时刻中间价市价进场"模拟，真实计划是限价或回踩成交，两者的选择效应方向未知。
- 反向对照里，AI 选的方向是 −0.066R，反过来做是 −0.18R，**AI 的方向略好**。所以不能说 AI 的方向毫无价值。

## 2. 我们自己数据的硬事实（Fedora，MAE/MFE 研究）

样本：AI 生成的入场假设按 品种×方向 12 小时去重后 **N=294**，覆盖 61 个品种、9 个 UTC 日。入场按决策时刻中间价
市价成交，路径用 15m K 线；同一根 K 线里止损和目标都被触及时，按先打止损算。

1. **价格噪音有多宽**：24 小时内最大不利偏移的中位数是 **2.23×ATR1h（2.54%）**。止损只放 1×ATR1h 或 1.2%
   时，24 小时内有 **72%～75% 会被打掉**。
2. **止损越宽亏得越少，但原因是手续费折成 R 后变小了**，宽止损本身并没有 alpha。3% 或 2×ATR1h 亏得最少。
3. **固定 1.5% 下限不合理**：ATR1h 中位数 1.13%、p90 2.13%，品种之间差异很大，下限应该随品种波动调整。
4. **目标太近会被手续费吃掉**：最近的 15m 反向结构位中位数只有 0.34% 远。命中率虽然有 70%～81%，扣费后
   却显著为负（−0.10R，置信区间 [−0.19, −0.03]）。目标至少要用 1h/4h 的结构位。2R、3R 目标在 24 小时内
   命中率只有 8%～33%。
5. **持仓时间是最显著的变量**：按方向算的平均收益，4h 是 **+0.13%**，12h 是 −0.38%，24h 是 −0.30%。几乎所有
   组合都是 4h 最好。**但 4h 是在同一批数据里挑出来的，属于样本内迹象，UNVERIFIED。**
6. **止损滑点**：本地轮询止损（0.4%）比交易所原生止损（假设 0.05%，未实测）每笔多亏 0.05～0.35R，止损越紧
   差距越大。这是 #3848 的直接经济依据。原生止损的真实滑点要等 #3848 上线后实测。
7. **锚点选错侧**：去重样本里有 14% 的锚点在入场价的错误一侧。
8. **分组线索（样本很小，只能当线索）**：
   - "均值回归 / 做空"（n=19）是唯一一个置信区间不跨 0 的组：24h +1.09%。
   - "动量 / 做空"（n=108）最差。
   - 这与之前 #3655 发现的"做空侧方向选择系统性反向"方向一致。

## 3. 候选几何设计

### 三个设计共同遵守的前提

- **每笔都必须挂交易所原生止损**（H4，#3848）。
  - 计划里的止损、交易所实际收到的止损、计算 1R 用的止损，三者必须来自**同一个保存值**。
  - 验收以从交易所读回的实际触发价为准。
- **止损只能往有利方向收紧，绝不放宽。**
  - 改止损必须原地改单，或者先挂新单、读回确认后再撤旧单，不能留下没有止损的空窗。
  - 改单失败就平仓。
  - 所有改单都经过 Execution Gateway。
  - 本地出场线和交易所止损线不一致时，以交易所止损为准。
- **AI 只选方向和结构锚点**（以后再加上形态类别），**所有价格由系统确定性计算**。告诉 AI 的参数从系统常量自动
  生成，避免提示词和代码两套口径。
- **工程前置**：
  - ATR 统一成一个口径（仓库里现在有 4 处各算各的）。这是 D0 还是 D1，要先查契约是否定义过 ATR 口径。
  - 盈亏比统一在实际可成交价上计算。

### 设计 A：结构止损 + ATR 缓冲 + 固定 R 目标 + 时间屏障（降摩擦基线）

- **入场**：限价或回踩，锚点取自 15m/1h/4h。截取锚点清单前先剔除方向错误的锚点。入场点离止损太远就不出计划
  （YTC 的"最晚入场价"）。
- **止损**：失效锚点外 0.5×ATR(该锚点周期) 与 1.5×ATR1h 取更宽的一个。如果低于成本下限，先换更高周期的锚点；
  换了还不够，就不出计划，不随意加宽。
- **止盈**：入场 + k×R，k 是待回放的参数，例如 1.5 / 2 / 3。
- **持仓管理**：浮盈 ≥1R 时移到扣费保本价。审查提醒：#3777 回放里，被打止损的单子有 33% 之后到达了原止盈，
  过早保本可能增加止损次数，所以这一步**标为未测试参数**。
- **时间屏障**：作为参数在 {2h, 4h, 8h} 一起检验，不预设 4h。
- **主要风险**：毛期望仍然约为 0，只是亏得慢一点；拒单率可能上升。

### 设计 B：结构止损 + 1h/4h 反向结构目标 + 分批止盈（YTC 两段式）

- **入场、止损**：同 A。
- **止盈**：
  - 第一目标：最近的 1h/4h 反向结构带，要求扣费后 ≥1R，在这里平一半。
  - 第二目标：下一个大级别结构带；如果是平滑趋势，改用吊灯跟踪止损。
  - 按 AstraQuant 的教训，第一目标锁定的 R 必须 ≥0.9。
- **持仓管理**：第一目标成交后，剩余仓位移到保本。
- **时间屏障**：第 3 根 1h K 线收盘时浮盈仍不到 0.5R 就离场；硬上限 12 小时。
- **主要风险**：
  - Bitget 部分止盈和多张止盈单的能力没核实。
  - 改单要等 #3848 PR-B。
  - 参数比 A 多。

### 设计 C：扫单回收入场 + 扫单极值外止损 + 对侧摆动点目标

**唯一试图改进"在哪里入场"的设计。**

- **入场**：价格刺穿 1h/4h 已确认的摆动点后，在 N 根 15m K 线内收盘收回，系统生成一个确定性事件，AI 从事件中
  选择。只能用 t 时刻之前已确认的摆动点，避免偷看未来。
- **止损**：扫单极值外 ≥0.3×ATR1h，避开整数位。
- **止盈**：对侧最近的 1h 摆动点。
- **主要风险**：
  - "收回后会反转"没有一手证据。
  - 事件可能很稀少。
  - 有 5～7 个参数。

### 与 PR #3780 的关系

建议拆开处理：
- "多周期锚点带"和"截取清单前先做方向过滤"可以先单独推进，修的是锚点选错侧的根因。
- "加宽止损"、"盈亏比门"和"止盈规则"等回放结果出来再定。

## 4. 评估协议

1. **第 0 步：随机入场基准（必须最先做）**。在同品种、同时段随机选时点入场，套用同一套几何，先把"方向优势"
   和"几何效应"分开。如果 AI 的方向和随机方向没有差别，A 和 B 的比较只能说明哪个少交摩擦。
2. **样本**：
   - A、B 用全部通过校验的 AI 入场假设（2216 条，其中 1653 条有完整路径）。
   - C 用全历史 K 线上的确定性事件。C 要和"同一批事件时点上用 A 的几何"或"同一批时点上随机方向"配对比较。
   - 补齐 15m 数据缺口（09-13～09-21、10-03～10-06），补出 1h/4h 锚点。
   - 样本外只用参数冻结以后的新数据。
3. **模拟纪律**：
   - 优先用 1m 路径。
   - 同一根 K 线里止损和目标都被触及时，按先打止损算。
   - 限价单必须被价格穿过才算成交。
   - 跳空时止损按开盘价成交。
   - 只用 t 之前已收盘、已确认的结构。
   - 原生止损滑点按 {0.05%, 0.15%, 0.4%} 三档做敏感性分析。
   - 能取到资金费率就计入。
4. **指标**：
   - 主指标：每笔平均净 R。
   - 辅指标：胜率（Wilson 下界）、盈利因子、超时离场占比、止损后又到目标的比例。
   - 全部按 族×方向×档位 拆开。
5. **置信区间与多重检验**：
   - 按 品种×日 分簇 bootstrap，日簇少于 30 时注明。
   - 参数网格预先登记，试验次数从这次的 138 个格子开始累计。
   - 用 Holm 或 Deflated Sharpe 校正。
6. **晋级门槛**：样本外 ≥100 笔、t>3、净 R 置信下界 >0。只是比基线亏得少的设计，只能作为"降摩擦默认值"，
   不能称为 alpha。
7. **Demo A/B**：
   - 前提：#3848 上线且通过读回验收。
   - 按候选 ID 哈希随机分组，风险、仓位、杠杆不变。
   - 停止条件：
     - 任意保护单没能在交易所确认，立即停止。
     - 50 笔后净 R 上界 <0，停止。
     - 累计回撤超过预先登记的 R 上限，停止。
   - 多次查看要预先分配显著性水平。

## 5b. Owner 对第 5 节六个问题的决定（2026-10-09）

1. **先证明方向选得对不对。** 这一项单独开讨论：#3858。
2. **最低盈亏比门槛：暂不设，先记下。** 以后作为回放参数再看。
3. **持仓时间上限：暂不做。** 持仓时间由 AI 决定。系统里已经有一套机制：持仓到达预期时长时，`position_manager` 会唤醒 Operator 做组合复查，AI 可以调整止损、目标或时长，也可以平仓（`portfolio/position_manager.py` 约 1194–1224 行）。另外还有一道硬上限，取 3 倍时长和 72 小时中较小的那个。目前没有的是：不看时长、定期对每个持仓重新复查。需要的话以后再讨论。
