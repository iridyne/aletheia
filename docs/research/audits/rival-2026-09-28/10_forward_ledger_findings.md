## 0. 先撤回一个错误论证

我此前写过「`stop_loss` 单项 −135.09 = 总亏损的 229%，若止损不亏 Round1 是 +76.07 盈利」。

**这是空洞的反事实，已撤回。** 止损亏钱是它的**定义** —— 它是设计上把单笔亏损截断在预定额度的机制。说「去掉止损亏损就盈利」等价于「如果亏的单子不亏就赚钱」，是同义反复，零信息量。

正确的问法是三个可证伪的问题：

1. 止损**触发得对不对**（被噪声扫掉 vs 方向确实错）
2. **执行价差多少**（这才是可回收的损耗）
3. **盈亏比是否匹配命中率**

直读后三个都有了答案，而且答案指向同一个地方。

## 3. 决定性检验：消除滑价并不能盈利

```
planned RR (median)  : 1.98   （止损距离中位 2.562% / 止盈距离中位 6.206%）
realised RR          : 1.45   （avg win 1.5118 / avg loss 1.0445）
decided-exit 命中率  : 18.0%  （stop_loss 232 : take_profit 51）
breakeven WR needed  : 40.9%
=> 缺口 22.8 个百分点
```

**假设止损全部在止损价成交（零滑价）：**

```
avg loss 1.0445 → 0.9895
realised RR 1.45 → 1.53
expectancy −0.5838 → −0.5387 USDT/笔   （仅改善 7.7%）
breakeven WR 仍需 39.6%，实际 18.0%
```

**即把滑价全部消除，期望值仍是 −0.54 USDT/笔。** 22 个百分点的命中率缺口不可能靠执行质量弥补。

**所以 #3619（交易所原生止损）的真实收益上界是 12.57 USDT，是卫生 + 安全项，不是盈利项。**

## 5. 结论与优先级修订

**真实失血点是信号质量，不是执行质量。** 方向毛边缘在**扣成本前**就是负的 ⇒ 执行链修复无法把负信号变正。

| 序 | issue | 变化 | 理由 |
|---|---|---|---|
| **1** | **#3652** 基于前瞻账本的准入收窄 | **新立，最高** | 唯一指向真实失血点；深度负组合幅度远超噪声 |
| 2 | #3618 滑点记账 | 保持 | 低成本，度量前提 |
| 3 | #3620 止损几何越过 entry | 保持 | 真缺陷（LTC +5.772%），但金额小 |
| 4 | **#3644** 归因链 | **降级** | 「按族归因不可能」已证伪；仍需补实盘侧归因，但前瞻账本已可回答核心问题 |
| 5 | **#3619** 交易所原生止损 | **降级** | 收益上界实测 12.57 USDT；卫生+安全项 |

**09-24 报告的核心结论在 140 倍样本上复现**（714 → 99,465 行）：**这是「策略没边缘」，不是「成本吃掉边缘」。**
