## 这个群是什么

一个聚焦 **「AI Agent + 加密合约交易」** 的中文社区，自称「研究院」，不发币、纯交流。核心范式是：

> **不让大模型实时盯盘做决策，而是用 AI（Claude/Codex/DeepSeek）以 vibe coding 的方式写出 Python 策略脚本，脚本本地/云端定时跑、推送信号到 Telegram，人或 Agent 再据此开单。**

群里几条主线：
1. **Clustr100 官方** —— 运营方（Wiggins LV、PIZZA、ZH Patrick/潜水观察员、热宝），做了 `clustr.academy` 教程站、CLUSTR100 信号 bot，主推 OpenClaw / Hermes Agent。
2. **猎人合约雷达 张德楷（@ZhangDeKai1203）** —— 做「庄家雷达 / 猎人量化手机雷达」，L2 级高频 + 半自动信号，写了一套《猎人交易法则》科普。
3. **一批自建系统的散户高手** —— 人世间、Allen.Ai、浪里个浪、白云苍狗、zh1p4ng、矩老师、PIZZA、挽北、Sorrows 等，各自用 AI 撸出选币/信号/自动交易系统。

## 与 Aletheia 的关系（仅对照，不构成施工授权）

本社区的范式与 Aletheia 有重叠也有本质区别，列出来便于将来讨论时引用，**不代表现在要去实现任何一项**：

| 维度 | Clustr100 社区做法 | Aletheia 现状 / 立场 |
|------|-------------------|---------------------|
| 决策主体 | 脚本算信号 + 人/Agent 手动开单（多为半自动） | 7 个 Agent 编排 → 风险引擎审批 → 执行网关；live 默认关闭 |
| 信号→下单 | 直连交易所 API/skill，常缺审批层 | 订单**只**走执行网关；risk/、execution/ 变更受控 |
| 数据源 | 币安/Coinglass/CoinGecko 自接，口径常出错 | 统一走 `get_market_data_provider()`；canonical `BTC/USDT` |
| 符号格式 | 链上名↔合约名靠人工映射表 | `aletheia/data/symbols.py` 统一，仅执行边界用 `to_bitget()` |
| 现实校准 | 普遍「回测漂亮、实盘亏损」、信号公开即失效 | 当前阶段红线：未证明连续稳跑、未证明学习产出可验证假设前推迟扩张 |

> **可借鉴的「思路」**（非「能力」）：盈亏比+回撤优于单看胜率、滑点波动率自适应、信号多层结构确认、双口径盈亏统计、AI 只做筛选/盯盘而非自主决策、关键规则硬编码。具体见各篇「关联阅读」与 [09](09_实盘业绩与现实校准.md) 末尾的「落地校准清单」。任何一项动工前都需单独授权。

> ⚠️ 免责声明：本知识库是对群聊内容的客观提炼整理，不构成任何投资建议。群内多数人**实盘是亏损的**，「回测漂亮、实盘打脸」是普遍现象（见 [09](09_实盘业绩与现实校准.md)）。任何策略都只赚特定行情的钱。
